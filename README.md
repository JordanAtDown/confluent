# Confluent

Seul sur un océan, le joueur navigue à la découverte d'indices, en vue à la première personne.
La connaissance est la progression : la fin est atteignable dès le début, à condition de savoir
comment. Jeu Godot 4.7, solo, PC.

## Jouer

**<https://jordanatdown.github.io/confluent/>**

Le build Web de `main` y est déployé à chaque push.
